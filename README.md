이 레포지토리는 프로그래머스(Programmers) 등의 코딩 테스트 플랫폼에서 해결한 문제들의 소스 코드와 풀이 과정을 기록하는 공간입니다. 백준허브(BaekjoonHub)를 통해 해결한 문제가 자동으로 업로드되고 있습니다.

## 🎯 Goal & Philosophy
- **깊이 있는 이해**: 단순히 테스트 케이스를 통과시키는 것에 만족하지 않고, 동료나 스터디원에게 구술로 명확히 설명하고 멘토링할 수 있는 수준의 완전한 이해를 지향합니다.
- **기본기 탄탄**: 컴퓨터 공학의 핵심 전공 지식을 기반으로, 효율적인 자료구조를 선택하고 논리적인 알고리즘을 설계하는 능력을 기릅니다.
- **꾸준한 기록**: 매일 꾸준히 풀고 기록하며 성장의 발자취를 남깁니다.
